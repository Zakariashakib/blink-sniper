# Face Landmarker model

`face_landmarker.task` is the official MediaPipe float16 Face Landmarker task bundle.

- Source: https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task
- Documentation: https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/python
- Downloaded: 2026-10-27
- SHA-256: `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`

It is loaded locally with the MediaPipe Tasks API. Runtime camera access does not require a network connection.
